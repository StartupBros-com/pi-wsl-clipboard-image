# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-03-10

### Added
- Initial public release of `@startupbros/pi-wsl-clipboard-image`
- WSL-first Pi extension for bridging the Windows clipboard into WSL screenshot workflows
- `/clipimg` and `/screenshot` commands
- `F6` shortcut to save the current Windows clipboard image and insert its temp file path into the Pi editor
- Optional VS Code-family terminal keybinding example for `/screenshot`
- Footer status hint for interactive Pi sessions on WSL
